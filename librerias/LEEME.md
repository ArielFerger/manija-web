# Librerías utilizadas

Se incluyen copias locales, conservando las cabeceras de sus autores:

- Bootstrap 5.3.8: https://getbootstrap.com/ (licencia MIT).
- jQuery 3.7.1: https://jquery.com/ (licencia MIT).
- DataTables 2.3.4: https://datatables.net/ (licencia MIT).

DataTables usa jQuery en esta versión. Los archivos se cargan desde el footer y se configura la tabla en `js/tablaProductos.js`.
